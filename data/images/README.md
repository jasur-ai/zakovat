# Savol rasmlari (zaxira nusxalar)

Bu papkadagi fayllar — **rasmli savollar uchun zaxira tasvirlar**. Fayl nomi savol id’siga mos:
`23339.jpg` → savol `id=23339`.

Bot rasmni quyidagi tartibda yuboradi:

1. Savolning asl rami (`attachments` dagi `cdn.zakovatklubi.uz` havolasi) — bu asl, aniq tasvir;
2. Asl rasm yuklanmasa, shu papkadagi generatsiya qilingan nusxa;
3. Ikkalasi ham ishlamasa, havola matn ko‘rinishida yoziladi.

Generatsiya qilingan rasmlar **ilustrativ**: ular savol matnida tasvirlangan ashyo/kartinaga
yaqinlashtirilgan ko‘rinish beradi, lekin asl nusxa emas. Shu sababli ular faqat asl rasm
yuklanmaganida ishlatiladi. `cdn.zakovatklubi.uz` yopilib qolsa ham o‘yin ishlashi uchun
kerakli minimum — shu fayllar.
